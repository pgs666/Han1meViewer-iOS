## Why

Commit subjects describe the development history, but a release changelog should describe the final behavior users receive. Several commits in this branch revert or replace earlier approaches, so copying every subject would incorrectly advertise removed behavior. The draft therefore uses the final diff as the source of truth and uses commit subjects only to recover intent and group related work.
