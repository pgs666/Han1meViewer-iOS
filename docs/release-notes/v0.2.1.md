# Han1meViewer iOS 0.2.1

> 0.2.1 是预发布版本。如有问题请到 [Issues](https://github.com/pgs666/Han1meViewer-iOS/issues) 反馈。

## ✨ 改进

- **下载视频现在会保留封面** —— 下载时会把当前视频封面一并保存到持久化下载目录，下载列表离线时也能正常显示；已有下载缺少封面时会自动补全
- **竖版相关推荐会自动匹配卡片布局** —— 检测到竖版封面的详情页后，iPhone 相关推荐改为三列，iPad 侧边栏改为双列，避免页面加载时出现封面拉伸和卡片形状跳变
- **iPhone 里番列表改为三列** —— 里番分类的“更多”页面使用更紧凑的三列竖版卡片；iPad 与普通横版分类保持原有布局

## 🐛 修复

- 修复播放页系列列表在默认收起状态下点击当前正在播放的视频仍会重复跳转的问题；展开后的完整列表与默认列表现在行为一致
- 删除已下载视频时会同时清理对应的持久化封面，不会留下无用文件；普通缓存清理不会误删下载封面

## 📦 安装

下方 `Han1meViewer-0.2.1-unsigned.ipa` 是未签名 IPA，自行重签后安装到设备即可（推荐 Impactor / AltStore / Sideloadly 等任一自签工具）。详细的下载、自签与安装步骤见 [README 的「安装」章节](https://github.com/pgs666/Han1meViewer-iOS/blob/v0.2.1/README.md#-安装)。
