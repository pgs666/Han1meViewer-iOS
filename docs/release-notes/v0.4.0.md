# Han1meViewer iOS 0.4.0

> 0.4.0 是预发布版本。如有问题请到 [Issues](https://github.com/pgs666/Han1meViewer-iOS/issues) 反馈。

## ✨ 改进

- **慢速网络下的播放更加稳定** —— 调整播放器的预缓冲与等待策略，减少网络较慢时频繁出现“播放一下、卡一下”的情况
- **加载状态与网络速度提示更加准确** —— 播放器现在会区分准备播放和缓冲状态，每次实际加载都会显示经过防抖处理的提示；网速改为按实时传输增量计算并进行平滑处理，不再长期空白或剧烈跳动
- **进度条现在会显示已缓冲范围** —— 播放进度之外会同时展示已经下载并可播放的区间，便于判断继续播放或跳转是否需要等待
- **新增网络较慢时自动降低画质** —— 可在设置中选择是否在连续缓冲时逐级降低画质，默认关闭；自动或手动画质切换都会保留当前播放位置、倍速和播放状态
- **播放器操作支持更多自定义** —— 可开启或关闭点击进度条跳转、左右双击快退或快进、左侧亮度手势和右侧音量手势；双击默认跳转 10 秒，也可以交换快进与快退所在的左右位置
- **播放失败后可以直接重试** —— 播放器会显示明确的错误状态和重试入口，并从当前画质与播放位置继续尝试

## 🐛 修复

- 修复播放失败被误当作正常播放结束、从而清空已保存播放进度的问题
- 修复画质切换后播放位置、倍速或暂停状态可能丢失的问题
- 修复播放器请求始终使用 Hanime1 Referer、导致自定义镜像站视频请求可能不正确的问题
- 修复 Cloudflare 验证页面可能读取到旧的 `cf_clearance` Cookie 后立即提示成功并自动关闭的问题；现在会等待当前页面实际完成验证，并检查 Cookie 是否有效或已经更新

## 📦 安装

最低兼容系统版本为 **iOS 16.0**。下方 `Han1meViewer-0.4.0-unsigned.ipa` 是未签名 IPA，自行重签后安装到设备即可（推荐 Impactor / AltStore / Sideloadly 等任一自签工具）。详细的下载、自签与安装步骤见 [README 的「安装」章节](https://github.com/pgs666/Han1meViewer-iOS/blob/v0.4.0/README.md#-安装)。
