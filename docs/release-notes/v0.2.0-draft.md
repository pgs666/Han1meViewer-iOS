# Han1meViewer iOS 0.2.0（草稿）

> 0.2.0 是预发布版本。如有问题请到 [Issues](https://github.com/pgs666/Han1meViewer-iOS/issues) 反馈。

## ✨ 改进

- **视频详情页改用稳定的左右分页布局** —— 简介与评论现在各自拥有独立页面和滚动区域，播放器下方内容可完整延伸至屏幕底部，左右切换时不再依赖容易互相干扰的手势拼接
- **播放器操作区更紧凑** —— 收藏、稍后观看、更多和分享固定为一行；加入列表、下载、原作漫画与网页入口收纳到“更多”菜单，并移除了容易造成布局跳动的播放器收起模式
- **系列视频改为底部弹窗浏览** —— 点击系列区域的“更多”会打开完整列表，选集后先关闭弹窗再进入对应视频，减少导航层级冲突
- **视频卡片与封面比例统一** —— 首页、搜索、作者页、相关视频和系列列表共用一致的卡片容器；普通视频保持横向封面，里番分类保留竖向封面，标题和元信息的高度也更加稳定
- **手机端相关视频固定为双列布局** —— 在不同屏幕宽度下保持整齐的两列卡片

## 🐛 修复

- 修复网站新版系列播放列表结构无法解析的问题，同时保留对旧版结构的兼容
- 修复 Hanime 卡片错误显示占位作者名，以及部分首页横向封面被错误裁成竖图的问题
- 修复发表评论或回复失败时输入窗口仍被关闭、内容被清空的问题；现在只会在发送成功后关闭并刷新
- 修复回复详情弹窗的下拉动作意外触发外层评论区刷新，以及弹窗之间刷新状态互相影响的问题
- 为评论、回复、搜索筛选、分享、系列列表等弹窗补充拖动指示器

## 📦 安装

下方 `Han1meViewer-0.2.0-unsigned.ipa` 是未签名 IPA，自行重签后安装到设备即可（推荐 Impactor / AltStore / Sideloadly 等任一自签工具）。详细的下载、自签与安装步骤见 [README 的「安装」章节](https://github.com/pgs666/Han1meViewer-iOS/blob/v0.2.0/README.md#-安装)。
