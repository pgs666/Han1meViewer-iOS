# Han1meViewer iOS 0.4.1

> 0.4.1 是预发布版本。如遇 Bug 或其他问题，欢迎到 [Issues](https://github.com/pgs666/Han1meViewer-iOS/issues) 反馈。

## ✨ 改进

- **快进快退秒数现在可以调整** —— 可在播放器设置中将双击快进、快退的跳转幅度设为 5–60 秒，默认仍为 10 秒
- **下载列表增加文件大小信息** —— 在每个下载项目的画质后显示文件总大小；已完成项目优先显示磁盘上的实际文件大小
- **滑动调节进度时反馈更加直观** —— 横向滑动播放器调整播放位置时，底部进度条会实时跟随预览位置，不再等到松手后才更新
- **进度变化提示位置更加合理** —— 滑动或双击快进、快退时，进度提示会显示在播放器上方，与长按倍速提示保持一致，减少对画面中央区域的遮挡

## 🐛 修复

- 修复启用“双击快进快退”后中央区域无法双击播放或暂停的问题；启用时左、中、右区域分别用于快退、播放或暂停、快进，关闭该功能后全屏任意位置双击均可播放或暂停

## 📦 安装

最低兼容系统版本为 **iOS 16.0**。下方 `Han1meViewer-0.4.1-unsigned.ipa` 是未签名 IPA，自行重签后安装到设备即可（推荐 Impactor / AltStore / Sideloadly 等任一自签工具）。详细的下载、自签与安装步骤见 [README 的「安装」章节](https://github.com/pgs666/Han1meViewer-iOS/blob/v0.4.1/README.md#-安装)。
