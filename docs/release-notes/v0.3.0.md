# Han1meViewer iOS 0.3.0

> 0.3.0 是预发布版本。如有问题请到 [Issues](https://github.com/pgs666/Han1meViewer-iOS/issues) 反馈。

## ✨ 改进

- **新增自定义镜像站支持** —— 设置中可以输入自定义镜像地址，并支持带路径的首页；应用会在保存前检查地址是否可用，清空输入后可重新选择预设站点
- **站点登录状态相互独立** —— 不同镜像站分别保存 Cookie 和登录状态，切换站点后不会再错误沿用其他站点的会话；登录页标题和提示也会跟随当前站点
- **站点切换流程更加明确** —— 更换预设站点或自定义镜像前会显示多语言确认弹窗；取消时保持原站点，确认后保存设置并自动退出应用，重新打开即可使用新站点
- **JavChu 使用独立首页分类** —— 首页和搜索选项会按照 JavChu 实际提供的内容显示，不再套用 Hanime1 的泡面番等分类
- **更新应用图标** —— 替换 iPhone、iPad 和 App Store 所需的全套图标资源

## 🐛 修复

- 修复从订阅列表打开作者页面时，短作者名可能命中其他作者视频、同时遗漏该作者作品的问题；订阅作者现在使用站点的订阅筛选接口，并对作者名再次精确校验
- 修复切换到 JavChu 后登录页仍显示 Hanime1 名称和说明的问题
- 修复自定义镜像地址、首页路径和预设站点选择状态与安卓版行为不一致的问题
- 修复部分 Cloudflare IP 封锁被当作普通验证失败处理的问题，现在会显示更准确的错误提示
- 修复网络图片首次加载失败后一直显示空白的问题，重新进入页面时会再次尝试加载
- 修复首页横幅在图片加载前后比例变化、导致页面布局跳动的问题

## 📦 安装
